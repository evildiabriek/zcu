## Zlist (ls)

Zlist est une alternative bas de gamme a ls.
Il est encore nouveau est n'a pas de belle sortie graphique mais il marche

``` C
// Zlist |>
// -d = display date
// -o = display owner
// -P = display permission
// -s = display size
// -a = dotfile dotfile
```
